# Contributing

Contributions are welcome once the first public release is available.

Please preserve PulseTap's core consent model: opting out must be easy, silence
must remain valid, timing limits must be enforced server-side, and decision
state must remain inspectable by the user.

Do not include real API keys, push subscriptions, conversation history,
personal information or companion prompts in issues, fixtures or pull
requests. Run `npm run check` before submitting code.
